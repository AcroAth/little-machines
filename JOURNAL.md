Companion documents: `design/north-star-spec.md` (design authority), `design/reference-analysis.md` (quality bar).*

## 2026-07-21 — Kickoff, landscape, vision

- Objectives set by the author: (1) a GitHub portfolio piece, (2) learn from public sources (lecture videos, notes, books, articles).
- Landscape survey: the "upload → flashcards/quiz/chat" shape is saturated (commercial SaaS + open source alike). The open niche: **generated** Brilliant-style interactive lessons. No active open-source project does it.
- Vision statement from the author: *"like interactive books for children, but for more advanced topics, within a website"* → the explorable-explanations genre. Taste calibration: **Mathigon's container × Nicky Case's soul**; explicitly not Brilliant step-quizzes, not Quantum Country memory-first.
- Standing constraint: **no audio, ever** (the author prefers quiet reading). Motion must carry the warmth sound normally would.
- Scope split settled: ingestion (a separate project) owns all source processing; this book is a pure learning/rendering layer over that project's structured output.
